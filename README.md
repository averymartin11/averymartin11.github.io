## Overview

For this assignment, I created two versions of a navigation menu using the same basic HTML structure. My goal was to make one navigation clean and easy to use and the other intentionally difficult and visually unappealing.

For the good navigation, I used a simple blue color palette, rounded corners, clean spacing, and a modern font. For the bad navigation, I used unusual colors, a decorative font, inconsistent styling, and an exaggerated hover effect.

## Process

I started with the provided HTML and CSS starter files and kept the existing structure and comments. I used CSS to style both navigation menus while keeping the required flexbox layout and responsive media query.

I tested the navigation in my browser and made adjustments to the colors, fonts, spacing, current link, and hover effects. Both versions use a vertical layout on smaller screens and switch to a horizontal layout on wider screens.
